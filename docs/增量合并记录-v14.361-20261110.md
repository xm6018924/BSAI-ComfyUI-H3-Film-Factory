## 三、本次做了什么

从 v14.339 整段复制以下内容，替换 v14.360 中的对应实现（函数级替换，不碰任何 widget）：

1. `_RP_LEGACY_LABELS` 字典（插在 upscaler 区块之前）
2. `_FF_UPSCALER_ARCH_CACHE = {}`
3. `_ff_upscaler_weight_path(name)` — 权重名 → 绝对路径
4. `_ff_probe_upscaler_arch(name)` — 只读 safetensors header，判定 pure-3D conv 能否 strict-load
5. `_ff_get_upscaler_models(compatible_only=False)` — 加架构过滤开关（默认 False，节点下拉仍列全量，老工作流存的值不会报 "Value not in list"）
6. `_ff_resolve_upscaler_model(name)` — `is_supported_model` 抛异常时改走 header 探针；备选列表用 `compatible_only=True`

替换边界：v14.360 原 4413-4470 行（`_ff_get_upscaler_models` 与 `_ff_resolve_upscaler_model` 两个函数）→ v14.361 合并后为 1,019,169 B。

再退成 bislerp 插值（画面变软却查不出原因）。现在能在运行前就判定并自动换权重。
